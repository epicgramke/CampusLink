# CampusLink Website

A responsive black-and-gold landing page for CampusLink, designed for Kenyan campus students.

## Files
- `index.html` — page structure and content sections
- `style.css` — responsive black-and-gold styling
- `script.js` — announcement, opportunity, event and WhatsApp link settings

## Publish with GitHub Pages on Android
1. Open `https://github.com/epicgramke/CampusLink` in Chrome and sign in.
2. Open the repository and tap **Add file** → **Upload files**.
3. Upload `index.html`, `style.css`, and `script.js` from this folder. Upload the files themselves, not the ZIP file.
4. Scroll down and tap **Commit changes**.
5. Open the repository **Settings** tab. If tabs are hidden on mobile, use the repository navigation menu or enable Chrome's **Desktop site**.
6. Open **Pages** under the **Code and automation** section.
7. Under **Build and deployment**, choose **Deploy from a branch**.
8. Select branch `main` and folder `/(root)`, then tap **Save**.
9. Wait a few minutes and revisit the Pages screen for the published URL. It will usually be `https://epicgramke.github.io/CampusLink/`.

## Important: customise before sharing
Open `script.js` and replace all sample `https://chat.whatsapp.com/` values with your real WhatsApp invite links. Edit the sample announcements and events to add verified information. The jobs/attachment links are examples; review them before publishing.

## Notes
- This is a public static website. No student login, database or admin dashboard is included.
- Google Fonts are loaded from Google Fonts; the site still has fallback fonts if they are unavailable.
- Never post private student information. Verify job offers and event details before publishing.
